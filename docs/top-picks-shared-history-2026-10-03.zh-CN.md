# Top Picks 按需冷启动与跨窗口行情复用

## 行为

- 无快照时，当前窗口按自己的原始日期范围下载并计算，先返回该窗口。
- 随后的后台预热/刷新，每轮只读取一次股票池，并获取一次一年行情。
- 四个窗口分别按原来的起止日期切片，再执行现有计算和样本门槛。不能直接从
  一年数据中取最后 N 个有效价格，否则缺失行情可能被窗口外的旧价格补进来。
- 普通预热跳过仍有效的窗口；强制刷新仍处理全部窗口，当前窗口先计算和发布。
- 初次打开 1Y 后，后台年度行情请求可命中底层行情缓存。初次打开短周期后，
  后台才获取一年行情，不把一年下载放在短周期首次响应的等待链路中。
- 沿用现有 20 秒轮询、后台刷新互斥和待刷新标记；一次行情读取可能包含多个
  股票网络请求及重试，不能把它理解为对供应商只发一个 HTTP 请求。
- 共享获取抛出异常时保留旧快照、释放刷新状态；单个窗口计算失败不会阻止其余窗口。

## 验证和计时口径

新增回归覆盖四个窗口按需冷启动、字符串/日期索引、稀疏历史、越界价格隔离、
完整行/告警/元数据一致性、强制刷新共享下载、优先窗口顺序、空股票池、闰日和异常恢复。

基准脚本：`scripts/benchmark_top_picks_refresh.py`。前后两条路径均使用上一轮已经
优化的年度批量计算器，本次对比只改变跨窗口获取方式。脚本使用隔离的临时快照
文件，不覆盖开发服务缓存，也不写入 Supabase。

- **冷启动**：快照为空且应用行情缓存已清空，到当前窗口生成并保存结果的服务层耗时。
  不包括 Python 进程启动、浏览器渲染及 HTTP 传输；不清除供应商或库内部缓存。
- **预热**：冷启动结果已可用之后，完成其余窗口的后台工作耗时。
- **刷新完成**：强制刷新开始到四个新快照均已生成并保存的耗时，不是立即返回旧结果的耗时。
- 通过控制后台任务执行时机，分别测量冷响应和后台完成时间，不包含前端等待下次轮询的时间。
- 真实测试读取当前 Supabase 股票池的前 5/20 只股票，另加默认基准 `^AXJO`；
  全部样本均有可用行情。该结果不能当作全股票池的真实网络耗时。
- 离线测试为 1,000 只模拟股票加基准，不包含网络耗时或人为网络延迟。
- 每个场景各执行一次，两种策略顺序运行；网络波动和运行环境会影响结果，不是稳定 SLA。

可复现命令（使用已安装后端依赖的 Python）：

```powershell
python scripts/benchmark_top_picks_refresh.py --live --limit 20 --as-of 2026-10-03 --windows 1D 1Y --env-file D:\Financial-Investment-Tool-env\.env --env-file D:\Financial-Investment-Tool-env\.env.local --output docs/benchmarks/top-picks-refresh-live-20-2026-10-03.json
python scripts/benchmark_top_picks_refresh.py --limit 1000 --as-of 2026-10-03 --windows 1D 1W 1M 1Y --output docs/benchmarks/top-picks-refresh-synthetic-2026-10-03.json
```

原始数据包含每次行情提供者调用的日期范围、耗时、可用股票数及实际完成刷新的窗口，
位于 `docs/benchmarks/`。其中 `*_downloads` 记录的是行情提供者调用，预热阶段可能命中缓存。

## 测量结果（秒）

真实 20 只股票加基准：

| 初始窗口 | 阶段 | 原按窗口下载 | 共用一年行情 |
| --- | --- | ---: | ---: |
| 1D | 冷启动当前窗口 | 10.165 | 8.935 |
| 1D | 后台预热其余窗口 | 27.956 | 8.721 |
| 1D | 后续四窗口刷新完成 | 33.341 | 1.178 |
| 1Y | 冷启动当前窗口 | 7.966 | 8.442 |
| 1Y | 后台预热其余窗口 | 23.948 | 0.209 |
| 1Y | 后续四窗口刷新完成 | 34.409 | 8.891 |

默认 1Y 场景的刷新耗时下降约 74.2%。冷启动算法未改，差异主要受请求与网络波动影响。
1D 优先的共享刷新中，行情提供者调用只有 0.920 秒，明显低于其他同规模年度下载的
约 8 秒；可能受上游或库内部缓存/网络波动影响，不能用这一轮宣称稳定达到 1.2 秒。
5 只股票预检中，两种初始窗口的旧刷新为 10.828/10.314 秒，共享刷新为 2.352/2.904 秒。

离线 1,000 只模拟股票加基准：

| 初始窗口 | 优化后冷启动 | 原四窗口刷新 | 共享四窗口刷新 |
| --- | ---: | ---: | ---: |
| 1D | 1.518 | 5.964 | 5.840 |
| 1W | 1.484 | 5.755 | 5.895 |
| 1M | 1.627 | 5.847 | 5.229 |
| 1Y | 0.783 | 5.629 | 5.439 |

离线结果没有显著一致的计算加速，符合本次主要减少网络下载的目标。不能把离线
1,000 只的时间当作真实股票池刷新时间。共享路径将每轮行情提供者调用从四次降为一次，
每个场景均确认四个窗口的生成时间已更新。
