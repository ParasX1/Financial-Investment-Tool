# Top Picks 年度指标批量计算

本轮优化一年窗口的重复数据处理，不改变轮询、缓存、行情下载或短周期窗口。

应用装配层将 `calculate_yearly_metrics` 注入 Top Picks 服务。服务拿到一份行情后，
一次提取价格、一次计算保留日期间隔的收益率；复用均值和标准差，以及同一组
股票/基准对齐样本。Alpha 直接复用本轮的 Beta，不再调用单项计算器重新计算。
原有逐项计算路径保留用于未注入批量计算器的调用者和对照验证。

为保持结果兼容，缺失日期的两种既有口径仍被保留：Sharpe、Beta、Alpha、
Information Ratio 和样本计数使用相邻日期收益；波动率与 Sortino 使用相邻有效
价格收益。没有内部缺口时共用收益数组和统计量，有缺口时分别计算必要的样本。
年度 200 个收益观测的展示门槛继续由原有服务层执行。

## 验证

- 38 项新增测试覆盖原计算器与批量路径的逐项数值对照、样本数、Sortino 状态、
  空/短历史、缺失数据、恒定价格、缺少基准、价格字段布局、Close 回退和输入不变性。
- 对照容差：相对误差 `1e-10`，绝对误差 `1e-12`。
- 服务测试验证年度路径只调用一次行情提供者，并跳过重复的单项计算器。
- 应用装配测试验证生产服务启用了批量计算器。

## 本地性能观察

固定随机种子 42，1,000 只股票加一个基准，260 个交易日，三轮计时：

| 路径 | 三轮耗时（秒） | 中位数（秒） |
| --- | --- | --- |
| 原逐项计算 | 9.0673 / 8.0798 / 7.9471 | 8.0798 |
| 批量复用 | 0.6566 / 0.7592 / 0.6893 | 0.6893 |

这次模拟测量的纯计算耗时下降约 91.5%。使用
`tests.top_picks.test_batch_analytics.market_frame(count=260, assets=1000)`
生成数据，`make_service(frame)` 与 `make_service(frame, optimized=True)`
作为两条路径；将 `src.metrics.fetch_stock_data` 替换为返回该行情的深拷贝，
用 `perf_counter` 测量各自 `_calculate_metric_maps(..., "1Y")`。

结果不包含真实行情下载、股票池查询、磁盘写入和浏览器轮询等待；原路径模拟
行情缓存命中。它不是端到端五秒刷新承诺，也不是性能门槛测试。
